# Lucide icons

Line icons from [Lucide](https://lucide.dev), version `1.78.0` (`lucide-static` package), ISC license (see `LICENSE`).

- Each file is copied unchanged from `lucide-static/icons/`; files are never edited by hand.
- Only the icons used by the interface are kept here. To add one, copy its file from the same Lucide version.
- `npm run build:icons` turns this folder into the sprite `dist/web/assets/icons.svg` and regenerates the icon names in `src/framework/ts/icons/icon-names.ts`.
